--------------------------------------------------------------------------------
1. WHAT THIS IS
--------------------------------------------------------------------------------
A "data-miner" fraud scanner aligned with the DOJ FOCUS initiative (Apr 2026),
which explicitly invites people who analyse PUBLIC data to file qui tam complaints.
It turns public research + federal-funding data into ranked, provenance-backed,
program-mapped, ethics-triaged CASE PACKAGES for whistleblower programs.

One pipeline, many domains:
  detect (signal) -> link/program-map -> reward estimate -> ETHICS triage -> case package

Domains live today:
  - Research integrity: undisclosed foreign funding (NIH x OpenAlex)
  - Research integrity: image duplication (Python PoC; pHash + ORB/RANSAC)
  - Research integrity: certification chain (paper -> grant -> false certification)
  - General federal funding: debarred recipients (USASpending x SAM exclusions)
  - Healthcare: excluded providers still billing (CMS x OIG LEIE)

5. DETECTORS & SIGNAL SCORING (probable cause, not proof)
--------------------------------------------------------------------------------
foreign_funding_mismatch : foreign affiliation/funder concurrent with an NIH award
  window (+/- grace). score 30 + 12*items + 10*(countries-1) + 20 if CN/RU/IR. Unit 7/7.
debarred_recipient : USASpending award recipient matches a SAM exclusion; name-match 45
  (UEI 70) + 25 if active at award start + 5 if > $1M. Unit 12/12.
excluded_provider : LEIE-excluded NPI in CMS payment data; NPI-match 60 (name 40) + 25 if
  payment at/after exclusion (reinstatement ends it) + 5 if > $100k. Unit 14/14.
image_duplication (Python) : pHash whole-panel + ORB/RANSAC rotation/scale/crop-invariant
  region reuse. Demonstrated catching a planted whole dup + a rotated splice, no FPs.
certification_chain (shared) : work produced under grant(s) -> implied false certifications
  (pi_oversight / allowable_expenses / full_disclosure) + counterfactual + linkage-weighted
  confidence. Unit 12/12.

6. ETHICS / PROPORTIONALITY (lib/extrapolator/src/triage.ts)  <-- user-requested
--------------------------------------------------------------------------------
Encodes: do NOT auto-escalate small entities, individuals, or plausible public-benefit
actors; deprioritize low-value cases; prefer human review and notify-first.
Recommended actions:
  hold_low_value        recovery < $150k (disproportionate to disruption)
  consider_notify_first small/individual subject OR claimed public benefit
  review                default human review
  escalate              ONLY large + value >= $1M + score >= 70
Every general case package renders an "Ethics & handling" section. It is a
recommendation to a human; it never acts on its own.

11. STANDING RULES (carried from MASTER-SPEC)
--------------------------------------------------------------------------------
- Signals = probable cause, never proof; default disclosure_state = internal.
- Publish nothing without US counsel; file-under-seal by default (FCA).
- Individuals are the relators, not the entity (Precision original-source trap).
- Human expert analysis is the original-source defence; record it (ri_original_source_log).
- Clean inputs only (open access / official APIs / public extracts). No Sci-Hub.
- Validate detectors against the ground-truth set. Honour the ethics triage.
- DOJ FOCUS: engage pre-filing with counsel on timing (FOCUS.dataminers@usdoj.gov).
